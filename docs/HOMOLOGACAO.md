# Roteiro de homologação da versão 1.0

Registre responsável, data, navegador, equipamento e resultado de cada item.

- [ ] Administrador entra e cria usuários dos quatro perfis.
- [ ] Usuário bloqueado perde acesso; cada perfil enxerga apenas os módulos permitidos.
- [ ] Cadastrar categoria e produtos unitário e fracionado; editar, ajustar estoque e arquivar.
- [ ] Abrir caixa, registrar suprimento e sangria e confirmar saldo esperado.
- [ ] Vender em dinheiro, Pix, débito, crédito e fiado; repetir uma venda com a mesma chave sem duplicá-la.
- [ ] Cadastrar cliente, receber pagamento parcial e quitar dívida.
- [ ] Cancelar venda como administrador e confirmar devolução ao estoque.
- [ ] Fechar caixa, conferir valor esperado, contado e diferença no histórico.
- [ ] Conferir dashboard, vendas, relatório de estoque, impressão/PDF e auditoria.
- [ ] Simular API indisponível, sessão expirada e acesso proibido; conferir mensagens ao operador.
- [ ] Testar leitor de código de barras e impressão nos equipamentos que serão usados.
- [ ] Gerar backup, restaurar em banco isolado e validar os principais totais.

Critério de aceite: nenhum erro bloqueador, nenhuma divergência financeira/estoque e todos os itens obrigatórios aprovados pelo responsável do mercado.
